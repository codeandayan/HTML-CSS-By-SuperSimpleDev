# Golden Age Web Development

> A six-month personal mission to transition from a full-time NADRA employee and final-year Software Engineering student into a professional Web Developer.

## Mission

This repository documents my six-month journey of building the skills, projects, portfolio, and professional presence required to get hired as a Web Developer.

The mission is built around one principle:

**I will not wait for more free time. I will use the free time I already have.**

My work schedule is demanding, but I have dedicated free time during NADRA duty and additional time at home.

I will use this time consistently.

---

## Timeline

**Start:** 06 September 2026
**Target:** 06 March 2027
**Duration:** 6 Months

This period is my **Golden Age of Web Development**.

The objective is to finish this period with:

* Strong JavaScript fundamentals
* Strong React skills
* Practical Next.js experience
* Backend and API knowledge
* Multiple real-world projects
* A professional GitHub profile
* A professional portfolio
* A strong LinkedIn presence
* A polished CV
* Interview preparation
* Active job applications
* A growing YouTube channel
* A clear path toward remote employment
